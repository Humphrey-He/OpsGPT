## 数据流设计

### 对话上下文管理

```
┌─────────────────────────────────────────────────────────────────┐
│                    Context Window Management                     │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │                     上下文窗口 (Context Window)            │   │
│  │                                                           │   │
│  │  ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐            │   │
│  │  │System  │ │History │ │Recent  │ │User    │            │   │
│  │  │Prompt  │ │Summed  │ │Msgs    │ │Current │            │   │
│  │  │(固定)  │ │(压缩)  │ │(完整)  │ │Query   │            │   │
│  │  └────────┘ └────────┘ └────────┘ └────────┘            │   │
│  │     500      2000      3000      500  ≈ 6000 tokens    │   │
│  │                                                           │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  策略:                                                          │
│  - System Prompt: 固定不变                                      │
│  - History: 定期总结压缩                                        │
│  - Recent: 保留最近 N 条完整消息                                │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 记忆系统架构

```
┌─────────────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   ┌─────────────┐                    ┌─────────────┐            │
│   │  Short-term │ ◀─────────────────▶│  Working    │            │
│   │  Memory     │                    │  Memory     │            │
│   │  (Redis)    │                    │  (Current)  │            │
│   └──────┬──────┘                    └──────┬──────┘            │
│          │                                  │                    │
│          │ 定期总结                         │ 上下文构建         │
│          ▼                                  ▼                    │
│   ┌─────────────┐                    ┌─────────────┐            │
│   │  Long-term  │ ◀─────────────────▶│    LLM      │            │
│   │  Memory     │                    │  Generation │            │
│   │  (Vector)   │                    │             │            │
│   └─────────────┘                    └─────────────┘            │
│                                                                  │
│   流程:                                                         │
│   1. 新对话 → 查询 Long-term Memory 相关历史                    │
│   2. 对话中 → 写入 Short-term Memory                            │
│   3. 对话结束 → 总结 Short → 写入 Long-term                     │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## API 设计

### REST API 端点

| 方法 | 端点 | 描述 |
|-----|------|------|
| POST | `/api/v1/chat` | 发送对话请求 |
| POST | `/api/v1/ingest` | 上传文档 |
| GET | `/api/v1/health` | 健康检查 |
| POST | `/api/v1/tools/execute` | 手动执行工具 |
| GET | `/api/v1/memory` | 获取记忆状态 |

### 请求/响应示例

```json
// POST /api/v1/chat
{
  "query": "A 服务昨天下午 3 点的 CPU 峰值是多少？",
  "session_id": "sess_abc123",
  "use_tools": true,
  "stream": true
}
```

```json
// Response (Stream)
data: {"type": "thinking", "content": "正在查询 Prometheus..."}
data: {"type": "tool_call", "tool": "prometheus_query", "params": {...}}
data: {"type": "tool_result", "result": {"cpu_peak": 87.5}}
data: {"type": "final", "content": "A 服务昨天下午 3 点的 CPU 峰值为 87.5%"}
```

## 配置设计

```yaml
# configs/config.yaml
app:
  name: "GopherSentinel"
  env: "development"
  log_level: "info"

llm:
  provider: "ollama"  # or "openai"
  model: "qwen2.5:7b"
  base_url: "http://localhost:11434"
  api_key: ""  # for openai
  timeout: 120

vector:
  provider: "qdrant"
  url: "http://localhost:6333"
  collection: "docs"
  embedding_model: "nomic-embed-text"

redis:
  host: "localhost"
  port: 6379
  password: ""
  db: 0

memory:
  short_term_ttl: 3600      # 1 hour
  long_term_summary: true   # 自动总结

tools:
  prometheus:
    url: "http://localhost:9090"
  loki:
    url: "http://localhost:3100"
  k8s:
    kubeconfig: "~/.kube/config"
  webhook:
    confirm_url: "http://localhost:8080/confirm"

security:
  rate_limit:
    enabled: true
    requests_per_minute: 60
  prompt_injection_check: true
  sensitive_words_filter: true

observability:
  langfuse:
    enabled: true
    public_key: ""
    secret_key: ""
    host: "http://localhost:3000"
```

## 技术选型理由

| 组件 | 选型 | 理由 |
|-----|------|------|
| **LLM 推理** | Ollama | 本地部署，成本低，隐私安全 |
| **向量数据库** | Qdrant | Go 原生，性能高，Rust 实现 |
| **缓存** | Redis | 成熟稳定，Go 支持好 |
| **日志** | Zap | 高性能，结构化日志 |
| **CLI** | Cobra | Go 标准 CLI 框架 |
| **监控** | Langfuse | 开源，专注 LLM 应用追踪 |
| **限流** | Redis 令牌桶 | 分布式环境友好 |
